# TextField

Libellé toujours visible au-dessus (`label`), aide en dessous (`ink-muted`), erreur écrite en toutes lettres en `danger` avec icône, qui remplace l'aide. Jamais le placeholder à la place du libellé. Largeur adaptée au contenu attendu, `reading-max` au plus. Bordure `line-strong` (≥3:1), focus `focus-ring`.

Le consommateur fournit : libellé, valeur, aide, message d'erreur, type (texte, email, téléphone avec indicatif pays, nombre, montant en FCFA).
