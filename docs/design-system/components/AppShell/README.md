# AppShell

Cadre de toutes les pages connectées. Barre latérale (`sidebar`, `surface-sunken`) : logo, sélecteur de workspace, navigation groupée (Accueil, Assistants, Systèmes connectés, Fonctions IA, Activité, Crédits, Réglages) avec l'élément courant en `primary-soft`. Barre du haut : recherche, jeton de crédits (`amber-soft`), notifications, `ModeToggle`, profil. Sous `bp-md` : la barre latérale devient un tiroir et une barre d'onglets en bas donne accès à Accueil, Chat, À valider, Crédits.

Le consommateur fournit : les entrées de navigation (filtrées par rôle, plan et feature flags), le contenu de la page.
