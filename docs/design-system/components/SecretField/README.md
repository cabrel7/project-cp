# SecretField

Affiche une clé API ou un jeton **une seule fois**, à la création : valeur en `code`, bouton « Copier », avertissement « Vous ne pourrez plus la voir ». Ensuite, seul le préfixe reste visible (`sk_live_4fT9…`). Jamais de secret dans une URL, un journal ou une notification.

Le consommateur fournit : la valeur (une fois), le préfixe, l'action de copie.
