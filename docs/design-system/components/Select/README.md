# Select

Pour choisir parmi 3 à 15 options connues. Moins de 4 options visibles d'un coup : préférer des boutons radio ou un `ModeToggle` segmenté ; plus de 15 : liste avec recherche. Libellé visible, option par défaut raisonnable.

Le consommateur fournit : libellé, options (valeur + libellé traduit), valeur, aide.
