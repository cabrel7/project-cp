# PageHeader

En-tête de chaque page : fil d'Ariane (pages de détail), titre `heading-1`, phrase d'explication en `ink-muted` en mode Simple, statut éventuel, et à droite l'action principale puis un menu « … ». Jamais plus de deux boutons visibles.

Le consommateur fournit : titre, explication, fil d'Ariane, statut, action principale, actions secondaires.
