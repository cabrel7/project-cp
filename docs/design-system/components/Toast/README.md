# Toast

Confirmation éphémère (4 s) d'une action que l'utilisateur vient de faire, en bas de l'écran (en bas au centre sur mobile). Une action d'annulation si l'action est réversible. Jamais pour une erreur bloquante (utiliser `Alert`) ni pour un événement externe (centre de notifications).

Le consommateur fournit : le message, une action optionnelle.
