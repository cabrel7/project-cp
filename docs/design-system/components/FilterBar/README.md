# FilterBar

Au-dessus d'une `DataTable` ou d'un tableau de bord, sur une seule ligne : recherche, 1 à 3 filtres, période (`ModeToggle` segmenté), vues enregistrées. Les filtres actifs sont visibles et effaçables d'un clic. En mode Technique, un bouton « Filtres avancés » ouvre un panneau.

Le consommateur fournit : filtres disponibles, valeurs, vues enregistrées.
