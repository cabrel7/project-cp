# CreditMeter

Portefeuille et budgets. Carte portefeuille sur `amber-soft` avec le solde en `amber-text` (« 12 430 cr »), une estimation en langage clair (« environ 18 jours ») et « Recharger ». Jauge de budget : `primary` jusqu'à 70 %, `warning` au-delà, `danger` à 100 %, toujours avec le pourcentage et les montants écrits.

Le consommateur fournit : solde, estimation de durée, budgets (nom, consommé, total, seuil).
