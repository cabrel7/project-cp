# DataTable

Base du gabarit Liste. En-tête sur `surface-sunken`, lignes de `body-sm`, ligne entière cliquable, statut en `StatusBadge`, montants alignés à droite en chiffres tabulaires, actions secondaires dans un menu « … ». Mode Simple : 3 à 5 colonnes utiles ; mode Technique : identifiants, versions, coûts détaillés en plus. Tri sur les colonnes utiles, pagination par curseur. Sur mobile, chaque ligne devient une carte.

Le consommateur fournit : colonnes (libellé, alignement, visible en Simple ou non), lignes, état (chargement, vide, erreur), sélection.
