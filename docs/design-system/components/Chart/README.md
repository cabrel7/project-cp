# Chart

Graphiques ECharts suivant la section *Graphiques et chiffres* : séries `chart-1` à `chart-6` dans l'ordre, grille `chart-grid`, texte en `ink`/`ink-muted`, un seul axe, légende dès 2 séries, infobulle au survol, vue tableau. L'aperçu montre des barres de consommation par profil de modèle sur 7 jours.

Le consommateur fournit : type (courbe, barres, barre empilée), séries nommées, unité, période.
