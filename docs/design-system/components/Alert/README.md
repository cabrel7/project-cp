# Alert

Message dans la page : titre court, phrase qui explique et **action proposée**. Variantes `info`, `success`, `warning`, `danger`, et `tip` (corail doux) pour les conseils d'onboarding. En mode Technique, une ligne `code-sm` ajoute le code d'erreur et l'identifiant de requête, copiables.

Le consommateur fournit : variante, titre, texte, action, code et identifiant de requête (optionnels).
