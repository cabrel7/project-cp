# ApprovalCard

Ce que l'IA veut faire, en clair, avant de le faire. Titre « À valider », résumé en une phrase (généré par `system.agent.approval_summary`), liste concrète des éléments touchés, montants, `RiskTag`, délai restant, et trois actions : « Approuver », « Modifier », « Refuser ». Apparaît dans le chat, la page Activité, la notification et sur mobile en plein écran. En mode Technique : paramètres exacts de l'outil.

Le consommateur fournit : résumé, éléments, risque, échéance, paramètres (Technique), actions.
