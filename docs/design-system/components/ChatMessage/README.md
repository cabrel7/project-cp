# ChatMessage

Messages du gabarit Conversation. Utilisateur : bulle `primary` à droite. IA : bulle `surface` à gauche avec la pastille IA ; les outils consultés apparaissent en puces repliables au-dessus de la réponse (« A consulté les commandes ») ; mention « Généré par l'IA — vérifiez les informations importantes » sous les réponses qui contiennent des chiffres ou des décisions. Les actions à valider s'insèrent comme `ApprovalCard`. `body-lg` en mode Simple.

Le consommateur fournit : auteur, contenu (texte, tableau, carte d'approbation), appels d'outils, état (en cours d'écriture, erreur).
