# Stepper

Étapes d'un assistant (gabarit G3), 3 à 5 étapes au libellé court. Étape faite : pastille `success` avec coche ; courante : `primary` ; à venir : neutre. Sur mobile : « Étape 2 sur 4 — Choisir les actions ». On peut revenir sur une étape faite ; le brouillon est sauvegardé à chaque étape.

Le consommateur fournit : étapes, étape courante, étapes terminées.
