# ModeToggle

Bascule **Simple / Technique**, dans la barre du haut, mémorisée par utilisateur (`ux.user_preferences.technical_mode`). Simple par défaut. Le mode Technique ajoute des informations (identifiants, JSON, codes d'erreur, colonnes, options avancées) sans changer la structure de l'écran. Contrôle segmenté réutilisable pour tout choix de 2 à 3 options exclusives (période 7 j / 30 j / 90 j).

Le consommateur fournit : les options, la valeur.
