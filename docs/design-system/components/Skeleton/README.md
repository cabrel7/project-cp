# Skeleton

Forme grise (`surface-sunken`) qui reprend la mise en page attendue pendant le chargement : lignes de tableau, tuiles, cartes. Pas d'animation si `prefers-reduced-motion`. Préféré aux spinners plein écran, pour que la page reste lisible sur un réseau lent.

Le consommateur fournit : la forme (lignes, tuiles, carte) et le nombre.
