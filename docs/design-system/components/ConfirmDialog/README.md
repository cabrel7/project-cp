# ConfirmDialog

Confirmation proportionnée au risque. Titre = question sur l'effet (« Supprimer l'assistant Relances ? »), texte = conséquence concrète, boutons nommés par l'effet. Risque élevé ou critique : bouton `danger` et, pour une suppression définitive, saisie du nom. Fermeture par Échap et clic sur le voile (`scrim`) sauf pendant l'action.

Le consommateur fournit : titre, conséquence, libellé de l'action, niveau de risque, nom à saisir (optionnel).
