# CodeBlock

Code, JSON, prompts et exemples de SDK, en `code` sur `surface-sunken`, avec bouton « Copier » et onglets de langage pour les exemples (TypeScript, Python, PHP, Dart). Surtout en mode Technique et dans la page « Intégrer à votre application ». L'édition de prompts et de JSON utilise CodeMirror avec les mêmes couleurs.

Le consommateur fournit : le code, le langage, les onglets éventuels.
