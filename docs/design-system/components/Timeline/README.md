# Timeline

Fil d'une exécution (run) ou d'une publication, en direct : une ligne par étape avec icône d'état, phrase en langage clair et durée. En mode Technique, chaque étape se déplie sur son détail (appel au modèle, outil, paramètres masqués, coût). Les étapes en attente d'approbation renvoient vers l'`ApprovalCard`.

Le consommateur fournit : étapes (type, état, texte, durée, détail technique).
