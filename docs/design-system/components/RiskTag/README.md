# RiskTag

Niveau de risque d'une action (outil MCP, action d'agent) : 1 à 4 barres + mot (Faible, Moyen, Élevé, Critique). Affiché dans la liste des actions d'un serveur MCP et dans `ApprovalCard`. Le niveau décide de la confirmation (voir *Patterns*).

Le consommateur fournit : `low` · `medium` · `high` · `critical`.
