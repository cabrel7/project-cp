# StatTile

Un chiffre clé qui répond à une question (« Combien de crédits me reste-t-il ? ») : libellé, valeur en `kpi` (chiffres tabulaires, unité toujours présente), variation avec flèche et mot, lien optionnel. 3 à 4 par rangée au plus. Préférer une StatTile à un graphique quand il n'y a qu'un chiffre.

Le consommateur fournit : libellé, valeur formatée (FCFA, crédits, nombre), variation et sens (bon ou mauvais), lien.
