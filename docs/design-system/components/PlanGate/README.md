# PlanGate

Une fonction hors du plan : on la montre avec ce qu'elle apporte et le plan qui l'inclut, jamais une page d'erreur. Fond `primary-soft`, icône cadenas, phrase de bénéfice, bouton « Voir les plans ». Une fonction pas encore ouverte (feature flag) n'est pas affichée du tout.

Le consommateur fournit : la fonction, son bénéfice, le plan requis.
